# 安全清单

## 当前状态

小程序通过微信 `code2Session` 登录，API 签发 7 天有效的 HMAC 访问令牌。业务接口统一验证 Bearer Token，并按当前用户校验关系、事件、回忆、提醒、共享和导出资源。生产环境禁用 `dev_*` 测试登录。

用户可在小程序个人中心注销账号，服务端会删除用户关系、纪念日、回忆、提醒、AI 记录、邀请、联系人连接与相关本地图片。客户端资料更新不能修改 VIP 等级。

登录、邀请、AI、语音和上传接口启用了进程内限流。未知服务端异常在生产环境只返回通用 500；健康检查在数据库不可用时返回 HTTP 503。

提醒发送只在微信 API 明确返回成功后记录 `SENT`。微信 Secret、access token 和 OpenID 不写入发送日志；用户手动“已处理”使用独立字段，不能伪造送达。订阅授权结果由微信客户端给出，拒绝授权不会阻止业务数据保存。

## 公开部署前必须完成

- 定期轮换 `AUTH_SECRET`；轮换后现有登录令牌会失效。
- 多实例部署前将进程内限流替换为 Redis 等共享存储，并增加安全审计日志。
- 将微信 Secret、AI Key、数据库密码放入 Secret Manager，并轮换历史上曾出现在文件中的密钥。
- 配置 HTTPS、严格 CORS、请求体大小限制和反向代理限流。
- 为图片能力 URL 增加更严格的短期签名或鉴权代理；当前 UUID 地址不可枚举、使用私有短缓存并随业务记录删除。
- 对日志进行脱敏，不记录 AI Key、微信 Secret、音频内容或完整用户隐私数据。

## 本地开发注意事项

`.env`、`.env.local`、日志和构建产物已加入 `.gitignore`。示例文件只包含占位符；如果旧版本文件曾被提交或共享，请立即在微信平台和 AI 服务商处撤销并重新生成密钥。
