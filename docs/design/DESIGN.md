# 与你 AI 小程序设计事实源

## 设计事实来源

- 版本：1.0
- 日期：2026-08-26
- 选定视觉方向：安静的关系仪表盘（低饱和森林绿、暖白背景、细边框、内容优先）
- 参考文件：`miniapp/src/App.vue`、`miniapp/src/pages/index/index.vue`、`miniapp/src/components/BottomNav.vue`
- 目标技术栈：uni-app + Vue 3，优先使用微信原生交互 API

## 用户与核心任务

- 目标用户：需要持续记住重要关系、日期和回忆的个人用户。
- 使用场景：打开小程序后快速确认下一件重要的事，并进入联系人、日历或记录。
- 唯一核心任务：在 10 秒内发现下一件需要准备的事并完成一个后续动作。
- 成功标准：首页能在加载、无数据、正常数据和未登录状态下给出明确下一步；点击事件、联系人、日历和新增入口均能到达对应页面。

## 设计原则

1. 先给任务优先级，再给内容浏览：下一件重要的事位于首屏，辅助统计和列表向下展开。
2. 用内容密度表达关系价值：避免把每个区块套成浮层卡片，列表使用分隔线保持扫描效率。
3. 关键动作只使用主色：森林绿用于主导航、主要 CTA 和当前日期；珊瑚色只表示提醒和风险。
4. 所有异步路径都有静态替代：加载、空状态、未登录和接口失败都保留可理解的返回或重试入口。

## 信息架构与导航

- 一级页面：此刻、关系、日历、我的。
- 全局新增：底部中间圆形入口和首页右上角新增按钮，打开原生 ActionSheet。
- 首页主路径：此刻 → 下一件重要的事 → 事件详情/AI 辅助。
- 浏览路径：此刻 → 未来一周 → 完整日历；此刻 → 最近在乎的人 → 关系详情。
- 专注态策略：创建、编辑和 AI 生成页面隐藏底部导航；返回后由页面生命周期重新加载数据。

## Design Tokens

### Color

| 语义角色 | Token | 值 | 使用规则 |
|---|---|---|---|
| 页面背景 | `color-bg-page` | `#F7F7F5` | 所有主页面背景 |
| 容器背景 | `color-bg-surface` | `#FFFFFF` | 可交互内容和表单 |
| 主文字 | `color-text-primary` | `#202522` | 标题、正文 |
| 次文字 | `color-text-secondary` | `#8B918D` | 辅助说明、日期 |
| 主操作 | `color-action-primary` | `#315C4D` | 主按钮、选中态、当前日期 |
| 提醒 | `color-feedback-warning` | `#C76755` | 提醒点、倒计时强调 |
| 成功/柔和主色 | `color-feedback-success` | `#E4ECE7` | 空状态图标底色、成功背景 |
| 分隔线 | `color-border` | `#DEDFD9` | 列表和区块边界 |

### Typography / Geometry

- 页面标题：`42rpx` / `56rpx` / 700；分组标题：`34rpx` / `48rpx` / 700。
- 正文：`32rpx` / 1.5 / 400-600；辅助文字：`26-28rpx` / 1.5。
- 页面水平边距：`28rpx`；常用间距：`12 / 18 / 24 / 32rpx`。
- 控件圆角：`9rpx`；内容容器圆角：`12rpx`；触摸目标不小于 `44x44pt`。
- 不使用 CSS 阴影：层级由 `1rpx` 边框、背景色差和留白表达，避免小程序渲染器下载阴影资源。

## 组件状态与代码映射

| 组件 | 状态 | 代码映射 |
|---|---|---|
| 下一件重要的事 | 加载/正常/首次为空 | `.loading-card` / `.next-card` / `.empty-next` |
| 未来一周 | 有事件/无事件 | `.agenda-list` / `.quiet-empty` |
| 最近在乎的人 | 有联系人/首次为空 | `.people-list` / `.add-person-row` |
| 底部导航 | 默认/选中/提醒徽标/未登录 | `.nav-item` / `.active` / `.nav-badge` / `requireLogin()` |
| 新增入口 | 打开/取消 | `openCreateMenu()` + 原生 ActionSheet |

## 内容、图标与素材

- 文案语气：具体、克制、面向行动；避免营销式口号。
- 图标来源：当前使用可读字符作为轻量占位，新增图标应优先接入项目已有图标资源或微信原生图标，禁止引入不匹配的 SVG。
- 头像：优先用户上传头像；缺省使用姓名首字和低饱和色块，不使用随机网络图片。

## 禁止项

- 不复制第三方产品 Logo、吉祥物、独有插画、品牌文案或整屏组合。
- 不使用渐变球、装饰性大插画和纯氛围背景抢占首页首屏。
- 不把所有信息区块嵌套成卡片，不用颜色单独表达错误或成功。
- 不在微信真机验证前宣称 H5 预览等同于小程序运行时。

## 验收标准

- 首页加载、正常、首次为空、未登录四类状态均可到达下一步。
- 首屏主任务在 iOS 和 Android 常见屏宽不被底部安全区遮挡。
- 主要文本与背景对比度达到可读要求，按钮触摸区域不小于 44pt。
- `npm run check` 构建通过；真机验收仍需在微信开发者工具完成。
