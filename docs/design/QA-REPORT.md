# 与你 AI 首页 Design QA

## 范围

- 页面：`miniapp/src/pages/index/index.vue`
- 组件：`miniapp/src/components/BottomNav.vue`
- 基线：uni-app Vue 3，`rpx` 尺寸，暖白背景与森林绿主色。

## 已检查项

- [x] 首屏主任务为下一件重要的事，空状态保留新增入口。
- [x] 首页包含加载、正常、无事件、无联系人和未登录分支。
- [x] BottomNav 为固定区域，页面底部预留安全区空间。
- [x] 事件、联系人、日历、记录均有可达路径。
- [x] 异步请求使用 `loadGeneration` 防止页面隐藏后旧响应覆盖新状态。
- [x] 主要颜色和圆角来自 App 级 token 或与其一致的局部值。
- [x] 首页请求失败呈现可理解的错误状态和“重新加载”操作，不再误显示为首次为空。
- [x] 远程头像加载失败时回退为用户姓名首字，避免显示破损图片。
- [x] 已从小程序样式中移除 `box-shadow` 声明，继续使用边框、背景色差和留白表达层级。
- [x] 已在 Vite 构建阶段移除 uni-app 运行时注入的 `shadow-grey.png` 预加载，防止微信开发者工具向 DCloud CDN 发起该请求。

## 未完成验证

- [ ] 微信开发者工具编译与页面栈检查。
- [ ] iOS/Android 真机安全区、字体和键盘行为。
- [ ] 弱网与接口超时的真实截图证据。

## 取舍与下一步

本轮不引入新插画、动画或第三方组件，保持现有 uni-app 技术栈和内容优先的信息密度。下一步应在微信开发者工具导入 `miniapp`，分别验证未登录、无数据、请求失败、头像加载失败和存在事件路径，并补充真机截图。
